# HahaTool 内容运营手册

所有内容都在 WordPress 后台维护：`http://localhost:8090/wp-admin/`。

> **先做一次设置**：文章编辑器右上 ⋮ → 首选项 → 面板 → 打开「自定义字段」，之后才能在编辑页底部看到字段表单。

## 一、添加一个新工具

1. 后台 → **文章 → 写文章**；
2. **标题**：工具名称（如 `ChatGPT`）；**别名（slug）**：英文短横线（如 `chatgpt`）→ 前台地址 `/tool/chatgpt`；
3. **正文**：建议结构「XX 是什么 / 核心功能 / 定价」（用二级标题块 + 列表块）；
4. 右侧 **分类**：勾选一个工具分类（不要勾 AI资讯/AI快讯）；**标签**：2-3 个场景标签；
5. 底部 **自定义字段**（名称区分大小写，全部小写）：

   | 名称 | 值 | 必填 |
   | --- | --- | --- |
   | `url` | 官网链接 | ✅（没有它不会显示为工具） |
   | `logo` | 推荐 `https://favicon.im/域名?larger=true` | 建议 |
   | `tagline` | 一句话简介（20 字内） | 建议 |
   | `pricing` | `免费` / `免费增值` / `付费` | 建议 |
   | `likes` / `monthly_visits` / `growth` | 收藏数 / 月访问量(纯数字) / 月增长率% | 可选 |
   | `rating` | 评分 0-5（如 `4.7`） | 可选 |
   | `scores` | 雷达五维：`易用性:9,功能强度:8,性价比:8,生态集成:7,中文友好:9` | 可选（详情页与 PK 页雷达图） |
   | `visits_history` | 近 6 月访问量，逗号分隔纯数字 | 可选（流量趋势图） |
   | `regions` | `美国:20.1,中国:15.3,其他:64.6` | 可选（地区分布） |
   | `faq` | 每行一条 `问题|答案` | 可选 |
   | `screenshot` | 截图 URL（不填自动生成） | 可选 |

6. 点击 **发布**，前台最多 60 秒生效。

## 二、广告运营位（重点）

全站 **6 个广告位已预置**，未上刊时前台显示「广告位 AD · 虚位以待」占位。上刊方式：给目标工具加自定义字段 **`promo`**，值为栏位名：

| `promo` 值 | 位置 | 数量 |
| --- | --- | --- |
| `home-mid` | 首页中部宽幅横幅 | 1 |
| `ranking-top` | 排行榜顶部横幅 | 1 |
| `detail-side` | 所有工具详情页侧栏 | 2（自动排除当前工具） |
| `detail-bottom` | 所有工具详情页底部横幅 | 1 |
| `tools-inline` | 工具库列表第 8 张卡后 | 1 |
| `news-inline` | 资讯列表信息流 | 1 |

另有：首页顶部 Banner（`banner=1`，2 个）、编辑精选（`featured=1`，8 个）。下刊 = 删除对应字段。所有推广均自动带「推广」标识。

## 三、维护榜单与 PK 数据

- 排行榜四个维度：`monthly_visits`（流量）、`likes`（收藏）、`growth`（增长）、收录时间（新品，自动）；
- 工具 PK 页（/compare）依赖 `scores` 五维与上述数据，建议保持五维 label 全站一致：**易用性 / 功能强度 / 性价比 / 生态集成 / 中文友好**；
- 数据按周/月更新，参考 SimilarWeb 等公开来源。

## 四、发布 AI 资讯与快讯

**长文资讯**：分类勾选 **AI资讯**（`ai-news`）。自定义字段 `cover` 填封面图 URL（头条大卡 / 列表缩略图 / 详情通栏）。正文支持富媒体：

- 图片：直接插入图片块或外链图；
- 视频：HTML 块粘贴 `<video src="xx.mp4" controls></video>` 或 B 站嵌入 `<iframe src="//player.bilibili.com/player.html?bvid=BV号" allowfullscreen></iframe>`，前台自动 16:9 通栏圆角；
- 媒体文件可在 后台 → 媒体 上传，生产环境建议用图床/对象存储外链。

**快讯（短讯）**：分类勾选 **AI快讯**（`ai-flash`），标题即快讯（30 字内），正文一两句。展示在首页跑马灯、`/flash` 时间线、资讯页侧栏。

## 四点五、审核用户提交的工具

前台 `/submit` 表单提交的工具会进入 后台 → **文章 → 待审**（pending）：

1. 打开待审文章：标题=工具名，正文含提交者邮箱与说明，`url / tagline / pricing` 字段已自动填好；
2. 核对收录标准 → 补全其余字段（`logo`、`rating`、`scores` 等）→ 修改别名为英文 slug → **发布**；
3. 不符合标准直接移到回收站。

> 提交接口凭据由 `scripts/setup-wp.sh` 自动生成（`.env` 中 `WP_APP_USER/WP_APP_PASS`）；接口自带字段校验与每 IP 每小时 3 次限流。

## 五、评论管理

后台 → **评论**：审核、回复、标记垃圾。演示环境为免审核直显；生产建议在 设置 → 讨论 中开启「评论必须经人工批准」。

## 六、内容规范

- 标题用产品官方名称；tagline 20 字内说清「谁 + 能干什么」；
- 数字字段填纯数字（前台自动格式化为 万/亿）；
- `ai-news` / `ai-flash` 为保留分类别名，请勿改名或删除。
